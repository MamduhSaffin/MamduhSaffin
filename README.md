### My working approach

- **Build for real people:** accessible, mobile-friendly and multilingual where useful.
- **Ship responsibly:** verify actual functionality, privacy, content quality and deployment.
- **Use AI carefully:** assist research and development without inventing capabilities or replacing qualified expertise.
- **Preserve continuity:** maintain existing working systems and document meaningful decisions.

I work with **HTML, CSS, JavaScript, TypeScript, React, PWAs, Supabase, GitHub Actions, Cloudflare and Azure**, while continuing to develop my technical skills.
